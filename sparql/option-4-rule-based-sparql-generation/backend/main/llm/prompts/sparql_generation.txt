- bibtex:Inproceedings: conference/workshop paper entry type

ENTITY LOOKUP PATTERNS:
Use entity NAMES in string literals, NOT URIs. Example patterns:

For authors:
  DBLP may store full names with middle initials (e.g., "Geoffrey E. Hinton" instead of "Geoffrey Hinton").
  For well-known authors, try exact match first, but if no results, use FILTER(CONTAINS(...)):
  ?author dblp:primaryCreatorName ?authorName .
  FILTER(CONTAINS(?authorName, "Hinton"))
  ?pub dblp:authoredBy ?author .

For venues:
  DBLP stores FULL venue names, NOT abbreviations. Examples:
  - "SIGIR" is stored as "Annual International ACM SIGIR Conference on Research and Development in Information Retrieval (SIGIR)"
  - "SIGMOD" is stored as "International Conference on Management of Data (SIGMOD)"
  - "KDD" is stored as "ACM SIGKDD Conference on Knowledge Discovery and Data Mining (KDD)"
  - "VLDB" is stored as "International Conference on Very Large Data Bases (VLDB)"
  - "NeurIPS" is stored as "Neural Information Processing Systems (NeurIPS)"
  - "ICML" is stored as "International Conference on Machine Learning (ICML)"

  To match venue abbreviations, use FILTER(CONTAINS(...)):
  ?venue dblp:primaryStreamTitle ?venueTitle .
  FILTER(CONTAINS(?venueTitle, "SIGIR"))
  ?pub dblp:publishedInStream ?venue .

For paper titles:
  ?pub dblp:title "Attention Is All You Need" .

YEAR HANDLING PATTERN:
  For conference queries, use ex:yearOfConference (preferred) with fallback to dblp:yearOfPublication:
  ?pub dblp:yearOfPublication ?pubYear .
  OPTIONAL { ?pub ex:yearOfConference ?eventYear }
  BIND(COALESCE(?eventYear, ?pubYear) AS ?year)

  For journal queries, use dblp:yearOfEvent with fallback:
  ?pub dblp:yearOfPublication ?pubYear .
  OPTIONAL { ?pub dblp:yearOfEvent ?eventYear }
  BIND(COALESCE(?eventYear, ?pubYear) AS ?year)

AUTHOR SIGNATURE PATTERN (for ordered author lists):
  ?pub dblp:hasSignature ?sig .
  ?sig a dblp:AuthorSignature ;
       dblp:signatureOrdinal ?ord ;
       dblp:signatureCreator ?authorUri ;

PUBLICATION TYPE FILTERING:
  For conference papers: ?pub dblp:bibtexType bibtex:Inproceedings .
  For journal articles: ?pub dblp:bibtexType bibtex:Article .
  For proceedings volumes: ?pub dblp:bibtexType bibtex:Proceedings .
